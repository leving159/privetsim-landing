Частые вопросы

Какие документы вы предоставляете?

Договор, счёт, акт и УПД через ЭДО или в бумажном виде. Для партнёров API и white label — отчёт о продажах каждый месяц.

Можно ли выдавать eSIM под своим брендом?

Да, для турагентств и интеграторов есть white label: письма, QR и кабинет с вашим логотипом. Условия — после заявки.

Как начисляются 25% блогерам?

С каждого заказа подписчиков, пришедших по вашей ссылке или промокоду, 25% зачисляются на ваш баланс в Привет SIM. Отдельные выплаты по договору — для партнёров API и white label.

Есть ли API?

Да: REST API для выдачи eSIM, пополнения и проверки остатка, вебхуки о статусах. Тестовый доступ — после подписания NDA.
